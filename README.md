## IP 类型：住宅、双 ISP、原生、机房，优先级怎么排

住宅 IP 来源是真实家庭宽带，平台看到的是一户正常上网的人家。双 ISP 指同一段地址在注册信息上挂在两个运营商名下，风控判断时比单一运营商更接近真实家宽。原生 IP 只说明这段地址注册在当地，不保证它是家宽属性。数据中心 IP 是机房批量分配的地址段，被标记的概率最高，用它推流出现零播放和限流是常见结果。

四类排下来：双 ISP 住宅 IP ≥ 住宅/家宽 IP > 原生 IP > 数据中心 IP。前两类的差别没有价格差那么大，实际选哪档看你目标市场的产品覆盖。

纯净度是第二个指标：这段 IP 之前被多少账号用过、有没有违规记录。共享 IP 或者被污染过的段，新号挂上去容易被牵连。WEPC 的英国页把“原生IP，可运营TK”直接写在标题下，澳洲页写“静态家宽IPv4 x1”，马来西亚和韩国标的是双 ISP 住宅 IP，这些描述对应的是不同的 IP 属性，价格差也主要出在这里。

## 带宽到底要多少：推流码率和套餐带宽是两回事

推流码率是直播间画质需要占用的上行速度：标清 2–3Mbps，1080p 建议 5Mbps 以上，手机推流 5Mbps 起，OBS 推流 6Mbps 起，多账号矩阵按账号数叠加。这是你实际要保证的速度。

套餐带宽是服务器网卡的上限，WEPC 最低的一款也给到 50Mbps，单路 1080p 用掉不到十分之一。真正需要盯的是月流量额度和超量后的限速。1000GB 按 5Mbps 推流估算约 440 小时，一天播 4 小时能用三个多月；1.5TB 约 660 小时。

## 拿到机器后要做的几件事

1. 开通后用 SSH 连服务器，Windows 机器用远程桌面。登录信息在开通邮件里。
2. 先把 BBR 打开。WEPC 英国产品页把“Please turn on BBR”写在了配置区，长时间推流时这个设置对稳定性有实际影响。

## 常见问题

**Q：月付还是年付？**
本次在 WEPC 公开页面没有核验到明确的年付折扣条款和退款政策。第一次买，先用月付跑一两周，把开播数据、延迟、流量消耗都测出来，再考虑拉长周期。没测过就年付，赌的是自己不换市场、不换套餐。

**Q：支持哪些付款方式？**
支付宝、PayPal 和信用卡。国内用户直接用支付宝，汇率按支付渠道结算。

**Q：ping 不通是不是机器坏了？**
部分海外 IP 段会禁 ping，这是 IP 提供方的要求，不影响实际推流和使用。判断机器是否正常，看 SSH 或远程桌面能不能连上。

**Q：一台机器能同时开几个直播间？**
看带宽和流量，不看账号数。单路 1080p 占 5–6Mbps，50Mbps 的套餐理论上能跑七八路，但流量会成倍消耗，2TB 的额度撑不住多路日播。多账号矩阵按账号数买机器，比在一台机器上叠账号安全。

**Q：做美区选 AS4837 还是 AS9929？**
两条线路的 IP 都是住宅属性，区别在回程优化和配置。4837 两档都是 1 核，¥61.37/月；9929 是 2 核，¥75.64/月。预算紧、单账号，4837 够用；要长时间稳定推流或者跑不止一个号，9929 贵出来的 14 块钱买的是线路和内存。
